## 변경 범위

ObservedWidthRepair는 BoundaryGuardedRepair를 상속하고 초기 삭제 반경만 조정한다.

- reference_path.closed=True이며 피팅 방식이 fallback인 획만 대상이다.
- 원래 입력의 추출 마스크(>.35)를 사용한다. 나중에 바뀐 예측에서 재추정하지 않는다.
- 예상 중심선 중 관측 잉크가 있는 비율이 .7 이상이어야 한다.
- 관측 중심선에서 예상 경로 근처(기존 반경+4 model pixels)의 표본을 고른다.
- 12표본 이상일 때 거리 변환 반두께의 중앙값을 사용한다. 먼 돌출은 표본에서 제외한다.
- 기존 반경을 줄이지 않으며 증가량 최대4, 새 반두께 최대8 model pixels로 제한한다.
- 경계 보호의 기존 여유1과 책임도 .5 조건은 유지한다.

관측 중심선에서 측정하는 이유는 기준 경로의 작은 위치 오차가 두께 과소 추정으로 이어지기 때문이다.
중앙값·경로 인접 조건·상한은 돌출 하나로 보호 영역이 과도하게 커지는 것을 제한한다.
이 설정은 첫 비교용이며 최적값이 아니다. 두꺼운 오류나 예상 경로에 붙은 오류까지 보호할 수 있다.

피팅 마스크·경로·복원 투영·손실·gradient step·보정 강도는 바꾸지 않는다.
특히 열린 곡선·접합부의 기존 문제는 이번 수정의 대상이 아니다.
다른 글자 전체를 기준 이미지로 다시 그리거나 최종 이미지를 합성하는 후처리는 없다.

## 출력과 판정

- shape_comparison.png: 글자별 여섯 결과.
- observed_width_calibration.json: 적용 대상, 표본 수·경로 지지율, 기존/관측/새 반경, 거절 사유.
- observed_width_initial_maps.npz / boundary_initial_maps.npz: 원본 초기 삭제 지도.
- 각 경로의 erase/restore/preserve 지도, clean prediction, trace와 projection_rounds.
- human_review.csv: 기존 오류 감소·굵기·윤곽·끝점·접합부·잔상 항목을 유지한다.
- automatic_metrics.csv: 동일 원본 전경과 중심선에서 비교한다. 폭 비율은 실제 굵기 변화율이나 정답률이 아니다.

정상 row148/202의 ㅇ와 row64에서 손상이 줄었는지, 생성 입력의 돌출·잡티 제거가 유지되는지를 함께 판정한다.
열린 곡선인 row131 등에서도 남는 손상을 별도로 기록한다. 초기 지도 감소만으로 성공을 선언하지 않는다.
