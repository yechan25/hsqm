# 원본 글자 구조 평가: 누락·추가·정션·분리

[점수 Colab](https://colab.research.google.com/github/yechan25/hsqm/blob/main/notebooks/structural_indicator.ipynb)은 입력 사진과 점수를 함께 표시한다. 기본 `MEASUREMENT_MODE="source"`는 실제 입력 잉크의 구조를 평가한다. `stored`는 이전 추출기 진단값 재현용이며 원본 글자 품질로 해석하지 않는다. 점수 계수는 사람이 정한 규칙이며 사람 평가에 교정된 척도는 아니다.

## 정상 이미지가 낮게 나오던 원인

고정 기준 좌표에서 추출 마스크를 검사하던 이전 경로는 두 오류를 혼동했다. 첫째, 위치·회전·크기 차이를 획 누락이나 추가로 처리했다. 둘째, 추출 모델이 실제로 존재하는 획을 다른 채널에 배정하면 원본에서도 획이 없다고 판단했다. 제공된 I_0_30.png의 첫 획은 원본에 존재하지만 기존 측정은 누락 0.993으로 출력했다. 감점 가중치 조정만으로 해결할 수 없는 측정 대상의 문제였다.

## 기본 source 알고리즘

1. **공통 좌표 정렬:** 전체 목표 이미지를 입력에 맞추는 하나의 제한된 affine 변환을 찾는다. 이동 ±12px, 회전 ±15도, 축별 배율 0.85~1.2, shear ±0.2가 기본이다. 목적 함수는 잉크 Dice 오차와 작은 이동 비용이다. 각 획을 따로 이동하거나 입력의 끊김을 메우지 않는다. 얻은 변환으로 입력을 목표 좌표에서 보간해 읽는다. 기준 획의 중심선은 다시 변형·스켈레톤화하지 않아 래스터 변형으로 가짜 분기가 생기는 것을 피한다.
2. **누락 M:** 기준 중심선 주변 2px에서 실제 입력 잉크의 최대값 c를 읽고 `mean(relu(1-c/0.7)^2)`를 계산한다. 추출 마스크의 채널 값은 사용하지 않는다.
3. **분리 D:** 기준 중심선의 지점 쌍 사이 제한 통로에서 입력 잉크를 max/min 연산으로 전파한다. 양 끝에 잉크가 있는데 연결 강도가 낮으면 감점한다. 고리에서는 반대편 우회로를 통로로 허용하지 않는다. 분리된 작은 잡음 자체를 분리 횟수로 세지 않는다.
4. **정션 J:** 여러 절대 잉크 임계값에서 입력 중심선 주위의 원형 방향 수를 검사한다. 같은 좌표·반경에서 목표 이미지의 방향 수도 읽는다. 원본 글자 전체에는 정상적인 획 교차점이 있으므로 이를 결함으로 세지 않고, 목표보다 늘어난 방향에 반응한다. 허용 방향은 최소 2이며 위치 오차 2px와 방향 오차 0.5를 허용한다. 초과 반응을 제곱하고 입력 중심선에 곱한 뒤 기준 획까지의 거리 가중치와 획 길이로 정규화한다. 이는 추가 분기의 연속 근사이며 빨간 원 개수를 점수에 넣는 방식이 아니다.
5. **추가 E:** 목표 잉크 주변 2px의 부드러운 허용 영역 A를 만들고 `sum(I*(1-A))/max(sum(I),1)`을 계산한다. 목표 잉크 내부에서 A=1이 되도록 정규화하여 같은 이미지에도 sigmoid 꼬리 때문에 기본 추가 감점이 생기지 않게 한다. 허용 영역을 입력 좌표로 옮겨 원본의 모든 픽셀에서 E를 계산하므로 정렬 과정에서 화면 밖으로 밀린 추가 잉크도 누락하지 않는다. 그림의 빨간색은 이 잉크 잔차이며 추가 획 개수를 확정한 결과는 아니다.

입력과 목표 기준·기준 획이 모두 필요하다. `reference_image`가 없는 오래된 NPZ에서는 source 모드가 명시적으로 실패한다. CSV로 새로 추론해 전체 목표를 저장하거나, 이전 진단 재현에 한해서 stored를 선택한다. 목표가 실제로 다른 글자이거나 허용 범위를 벗어나는 변형에서는 정렬이 실패할 수 있다. 결과의 정렬 파라미터와 Dice, 카드의 **정렬 후 입력과 기준 보기**를 확인한다. 정렬로 허용한 회전·크기·기울기 자체는 이 구조 지표에서 감점하지 않는다.

## 점수 변환

기존 v3의 감점 설정은 그대로 유지한다. 기본 가중치는 모두 1이다.

    rM_k = 1-M_k
    d_k = D_k/0.2,  rD_k = 1-0.60*d_k/(1+d_k)
    j_k = J_k/0.01, rJ_k = 1-0.65*j_k/(1+j_k)
    q_k = 100*rM_k*rD_k*rJ_k
    Qmix = 0.5*mean(q_k)+0.5*min(q_k)
    C_M = 100*min(rM_k), C_D = 100*min(rD_k), C_J = 100*min(rJ_k)
    C_E = 100*exp(-max(E-0.03,0)/0.025)
    Q = min(Qmix,C_M,C_D,C_J,C_E)

거의 사라진 한 획은 다른 정상 획이 많아도 C_M으로 전체 점수를 제한한다. 분리·정션 단독 감점 한도는 60/65점이다. 복합 오류와 서로 다른 심각도에서는 사진들의 순서가 항상 고정되지는 않는다. 파일명이나 정상 표본의 이름으로 점수를 지정하지 않는다. 정상에 가깝게 맞도록 사후에 점수를 올리는 하한 보정도 하지 않는다.

## 다른 이미지 / 기존 결과 실행

독립 노트북은 `MODE="csv"`가 기본이며 테스트 CSV에서 12장을 골라 평가한다. `RANDOM_SEED`를 바꾸면 다른 표본, `SAMPLE_COUNT`는 장수, `INPUT_FILES=["실제파일명.png"]`는 파일명 선택이다. `INPUT_FILES=None`, `SAMPLE_COUNT=None`은 전체 평가다. 선택한 CSV 행과 파일명을 먼저 출력한다. 입력 획 정답 주석은 사용하지 않는다.

이미 추론한 결과를 고치려면 `MODE="auto"`를 사용한다. 현재 런타임의 `structure_results` 또는 `REPORT_PATH`의 NPZ를 새 source 방식으로 재측정하므로 모델을 재학습하거나 재추론할 필요가 없다. 수치만 테스트하는 `MODE="values"`는 stored 공식을 사용한다.

모든 가중치·점수 계수는 첫 셀 `SCORE_CONFIG`, 새 정렬·측정 설정은 `SOURCE_CONFIG`에 있다. source 모드에서 이전 `extra_radius`/`extra_alignment` 설정은 사용하지 않으며 SOURCE_CONFIG가 우선한다. 추가 감점 계수와 허용 비율은 여전히 SCORE_CONFIG의 extra_scale/extra_allowance다.

사진은 NPZ의 실제 평가 입력을 우선 표시한다. HTML/PNG 갤러리, 글자별/획별 CSV, 설정·등록 파라미터·새 측정값·기존 추출기 측정값을 담은 `indicator_report.json`을 저장한다. `extra_0001.npz` 등에는 원본 좌표의 입력·추가 지도와 기준 좌표의 정렬 입력·목표·정션 지도도 저장한다. 주 사진은 원본이고 펼침 그림은 진단용 정렬 사진이다.

실행 뒤 **진단 ZIP 다운로드**로 평가한 배열과 감점 내역을 함께 받는다. 이미 실행한 런타임에서는 [진단 ZIP 추가 셀](../../notebooks/export_indicator_debug_cell.py)을 마지막 새 셀에 붙인다. 체크포인트나 전체 데이터셋은 포함하지 않는다.

## 확인한 범위

사용자가 제공한 진단 ZIP은 정상 초 변형 11장과 실제 획 삭제 1장이다. v4 재측정에서 정상 11장은 모두 100점이고, 삭제는 약 21.5점이다. 정상은 전체 affine 정렬 후 구조가 일치하므로 구조 오류값이 거의 0이다. 별도 제공된 실제 분리 예제는 기준 획 배열이 같은 것을 확인하고 ZIP의 전체 목표를 사용했을 때 약 70.3점이다. 이 자료는 설계에 사용한 개발 표본이며 독립 검증 자료가 아니다. 모든 폰트나 글자에 대한 정확도를 입증한 것은 아니다.

## 기울기와 역확산

Affine 최적화는 SciPy를 사용하는 평가용 전처리로 입력까지 미분하지 않는다. `register_reference`에서 파라미터를 한 번 구한 뒤 `PreparedSourceMetric(target,strokes,parameters=...)`를 고정해 호출하면, 입력 보간·M/D/J/E와 점수의 Tensor 경로는 입력 기울기를 유지한다. min/max/ReLU에는 부분 기울기를 사용한다. 정렬까지 포함한 완전 미분 가능 역확산 파이프라인이나 scheduler 연결은 구현하지 않았다.
