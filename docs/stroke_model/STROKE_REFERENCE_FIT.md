# 추출 위치에 맞춘 정상 기준 획 변형 확인

[Colab](https://colab.research.google.com/github/yechan25/hsqm/blob/main/notebooks/stroke_reference_fit.ipynb)에서 L4로 1→2→3번을 실행한다. 역확산은 수행하지 않는다. 새 모델을 학습하지 않으며 기존 best.pt의 softmax/마스크/flow hints를 추론에 사용한다.

1번은 Drive를 연결하고 기존 오류 이미지 baseline, 당시 기준 획, 정확히 대응하는 checkpoint를 불러온다. 기존 생성 실험 폴더에서 복원하거나 guidance_debug (4).zip을 사용한다. SHA256 대응 검사를 유지한다. 자료는 /content로 복사해 처리하고 마지막 ZIP을 Drive의 HSQM/stroke_reference_fit_results에 저장한다.

2번은 네 글자에서 획별 softmax, 잉크 마스크, 모델이 flow로 변형한 기준 획 hints를 저장하고 표시한다. checkpoint가 hints를 제공하지 않으면 원래 기준 획으로 시작했다는 플래그를 저장한다. 이미지 해상도/마스크 형태는 기존 추출 모델의 128 좌표를 사용한다.

3번은 정상 기준 획의 중심 경로를 추출하고, 추출 마스크의 주된 연결 성분/주된 경로에 맞춘다. 후보 연결 성분은 잉크량과 초기 hints에 대한 근접성으로 선택한다. 짧은 부가 가지는 가장 긴 주 경로에서 제외되며, 분리 문양을 무조건 이어 붙이지 않는다. 직선 기준은 robust TLS로 직선을 유지하고, 곡선은 기준 구조와 모델 hint 초기화에서 부드럽게 변형한다. 이동, 길이 비율, 획 폭에 한도를 둔다. 폭은 추출 마스크 중심부에서 추정한다. 기준의 한 픽셀 래스터를 직접 확대하면 톱니/회색 획이 생기므로 변형된 기준 중심선과 폭으로 anti-aliased 정상 획을 다시 렌더링한다. 따라서 원본 픽셀/끝 모양을 그대로 보존하는 비트맵 워프는 아니며, 끝이 둥글어지는 등의 스타일 차이가 있다.

기준 획 마스크가 짧은 중심선만 제공하는 경우 접점 부근의 선분이 생략돼 있을 수 있다. 전체 기준 글자의 잉크가 연결을 확인해 주는 경우에만, 짧은 획 끝을 다른 획의 대응 접점까지 제한적으로 연장한다. 나머지 접점 차이는 작은 공동 이동으로 줄인다. 연결을 확인하지 않고 임의 브리지를 그리지 않는다.

폐곡선/복잡한 원본 분기는 중심 경로 하나로 자르면 원래 모양을 잃기 때문에 제한된 affine으로 대체하고 경고한다. 이 대체 경로는 곡선 변형/굵기 재구성까지 지원하는 경로가 아니다. 빈/불확실한 추출은 실패를 숨기지 않고 경고와 함께 원래 기준 획을 남긴다. 길이/이동 한도를 넘는 추출도 경고를 남기고 초기 위치를 유지한다. 따라서 잘못된 후보가 나올 수 있으며 최종 정답이나 보정 성공으로 간주하지 않는다.

출력은 획별 원본/hints/추출/변형/겹침 비교, 정상 후보 PNG, 학습 추출기 없는 nearest-reference 대응 대조군, 삭제/복원 차이 지도, 획별 수치/경고와 NPZ다. 삭제·복원 지도에는 정렬 오차와 스타일 차이도 포함될 수 있다. 이번 단계에서는 이 지도를 역확산에 사용하지 않는다.

획 추출 모델의 역할은 대응 획의 관측 위치와 hints 초기화를 제공하는 것이다. 대조군도 비슷한 후보를 만든다면 모델 고유의 이득이 입증된 것이 아니다. 실제 효과는 다른 폰트·위치·곡률을 가진 생성물에서도 비교해야 한다.

로컬 검증은 직선의 이동/부가 가지 배제, 곡선 변형, 분리 문양 제외, 폐곡선 fallback, 접점 보완, 진한 획 렌더링 및 빈 추출 경고를 포함한다. 사용자의 기존 ZIP에서 저장된 실제 추출 마스크로 초기 후보도 확인했다. 로컬 예비 비교는 hints가 저장되지 않은 파일이므로 원래 기준으로 초기화했으며, 실제 GPU에서 모델 flow를 새로 추출한 결과와 구분한다. 코랩에서 생성되는 normal_candidate.png는 참조 조건 기반 합성 후보이며 확산 모델 출력이 아니다.
