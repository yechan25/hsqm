# 실제 저장 배열로 재현한 정션 과검출 수정

사용자가 제공한 4개 NPZ(cut1/sub1/add1/다른 폰트)를 같은 입력으로 재실행했다. 원본 배열과 생성 결과는 git에서 제외되는 outputs에만 두며 저장소에 올리지 않는다. 이 자료는 수정에 사용한 개발 회귀 사례로, 독립 검증 자료가 아니다.

## 확인한 원인

1. 일반 skeleton도 굵은 꺾임·절단 끝에서 짧은 가지를 만든다. 한 픽셀의 이웃만 세면 정상 경로에 여러 정션이 있다고 오판할 수 있다.
2. morphology 기반 soft skeleton은 실제 thinning 결과와 다르다. 누락 획의 얇은 잔상에서도 soft 고리의 값이 갈라져 큰 J가 나왔다.
3. 수준별 최대 반응을 픽셀마다 고르면, 서로 다른 수준의 불안정한 후보가 누적된다.

## 이산 진단 수정

- skeleton을 그래프로 만들고, 직각 모서리에 생기는 중복 대각선 연결을 제거한다.
- 3개 이상 이웃이 있는 위치마다 실제 경로를 따라간다.
- 접합부 검사 반경은 max(2, 1.25 × 국소 획 반경 + 1) 픽셀이다. 이 영역 밖까지 독립된 세 경로가 이어지는지 검사한다.
- 영역 안에서 다시 합쳐지는 경로는 한 경로로 본다. 안에서 끝나는 짧은 경로는 미확정이다.
- 2픽셀 이내 위치에서 두 개 이상의 절대 잉크 수준에 걸쳐 확인된 후보를 빨간색으로 표시한다. 같은 접합부의 중복 후보는 합친다.
- 남은 짧은 후보·한 수준에만 있는 후보는 노란색이다. **정상으로 면제한 것이 아니라, 현재 해상도와 설정으로 정션이라고 확정하지 못한 것이다.**

검사 반경과 수준 수는 설정값이다. 반경을 늘리면 짧은 실제 가지도 미확정이 될 수 있다. 빨간 원 0개라도 노란 원이 있으면 정상으로 단정하지 않는다. skeletonization에서 처음부터 사라진 1픽셀 돌기는 이 방법도 찾지 못할 수 있다.

## 미분 가능한 근사 수정

기존처럼 soft skeleton의 국소 반응만 보지 않고, 실제 occupancy의 원형 고리에서도 세 방향이 유지되는지 함께 본다.

1. 여러 절대 수준에서 soft occupancy와 soft skeleton을 계산한다.
2. min-plus chamfer 반복으로 배경까지의 거리를 연속적으로 근사한다.
3. 1.5 × 국소 거리 + 1 픽셀 반경에서 실제 occupancy를 48방향으로 bilinear sampling한다.
4. 각도 방향을 3회 평활해 픽셀 수준 진동을 줄인다.
5. 원형 고리의 세 방향 반응과 주변 soft skeleton 분기 제안이 함께 있는 곳만 남긴다.
6. 수준별 반응은 최대 대신 평균한다.

학습 경로는 전부 PyTorch 연산이다. 이산 진단 그래프를 detach해서 학습 손실에 억지로 붙이지 않았다. min/max 동률 등에서 부분 기울기를 쓰는 제한과, soft/이산 진단 불일치 가능성은 남는다.

## 같은 배열의 전후 비교

| 사례 | 이전 | 수정 후 |
|---|---|---|
| cut1 2번 획 | 빨간 후보 4곳 | 확정 0곳, 미확정 후보로 분리 |
| cut1 5번 획 | 한 수준의 후보 1곳 | 확정 0곳, 미확정으로 분리 |
| sub1 4번 누락 잔상 | J_soft 약 0.02328 | J_soft 0 |
| add1 2번 세로획 | 빨간 후보 4곳 | 실제 접합부의 확정 1곳 유지 |
| 다른 폰트 2번 세로획 | 빨간 후보 2곳 | 실제 접합부의 확정 1곳 유지 |

J_soft는 확정 개수가 아니다. 예를 들어 cut1 2번은 약 0.000679, 다른 폰트 2번은 약 0.000450으로 여전히 크기가 겹친다. **J_soft만으로 정션 여부를 결정하거나 원본 품질 벌점으로 바로 쓰지 않는다.** 학습 효과와 다른 폰트에서의 일반화는 아직 검증하지 않았다.
