# 저장된 오류 탐지기 지도로 실제 재역확산

[추론 Colab](https://colab.research.google.com/github/yechan25/hsqm/blob/main/notebooks/detected_extra_diffusion.ipynb)

이 노트북은 학습을 실행하지 않는다. 학습한 오류 탐지기(best.pt, stroke_error_localizer_v1, epoch>=1)와 그때 사용한 획 추출기를 불러온다. 기존 two_stage_repair의 생성물 PNG를 바로 사용한다. 생성물의 오류를 먼저 찾고 재역확산하는 과정만 실행한다.

1. 준비·Drive 연결.
2. ERROR_CHECKPOINT는 새 오류 탐지기, CHECKPOINT는 그 학습에 사용한 기존 획 추출기다. 기본값은 error_localizer_runs의 최신 best.pt와 그 metadata의 원래 획 추출기 경로다. 해시 일치 검사를 한다. FIRST_IMAGE는 기존 2×2 생성물이며 기본은 저장된 two_stage_repair stage1의 최신 PNG다.
3. 같은 네 문자의 표준 획 조건을 선택하고 목표 문자를 순서대로 입력한다. 표준 RGB는 VAE의 입력이나 보정 목표가 아니다.
4. 저장 모델의 오류 확률과 임계값으로 만든 지도를 확인한다. 현재 threshold=.5는 미보정 진단값이다. 낮은 확률을 자동으로 좋은 지도라고 해석하지 않는다. 잘못된 지도일 때는 재역확산으로 해결하지 못한다.
5. 실제 DDIM 재역확산. 두 경로가 저장 생성물을 한 번 재인코딩/재잡음한 같은 잠재값에서 출발한다. baseline은 재역확산만, guided는 고정된 모델 오류 지도의 국소 손실로 clean latent를 보정한다. 학습/최초 폰트 렌더링은 없다.
6. 원래 생성물 / 재역확산만 / 탐지 지도 가이드 결과와 단계별 예상 완성 이미지를 확인하고 ZIP을 받는다.

## 수정 목표와 범위

오류 탐지기는 참조의 픽셀 차이가 아니라 실제 입력에서 오류 지도를 예측한다. 기존 추출기의 표준 획 조건 의존은 남는다. 이미 학습한 복원 제안기는 아직 없으므로, 이 추론 버전은 '추가 잉크 삭제'만 지원한다. 마스크 주변 6픽셀 ring의 밝은 관측 픽셀에서 배경색을 추정해 고정 목표로 사용한다. 깨끗한 정답 이미지나 표준 고딕체 RGB를 목표로 사용하지 않는다.

현재 지원 조건은 밝고 대체로 단색인 배경의 문자 crop이다. 배경 추정이 어둡거나 충분히 불균일하면 중단한다. 이 간단한 검사는 임의의 사진 배경에서 안전한 복원을 보장하지 않는다. 실사진/질감 배경/누락 획 복원은 별도 inpainting/복원 헤드가 필요하다.

L = mean_E((RGB-T)^2 + 0.5 abs(RGB-T)) + keep_weight * (mean_P((RGB-I0)^2) + max_5x5_P_MSE).

E는 검출된 고정 오류 마스크, P는 그 밖의 영역이다. T는 현재 생성물에서 추정한 국소 배경색이다. 단계마다 이 손실을 VAE 출력에서 잠재값으로 미분한다. clean_residual 방식으로 다음 상태에 반영하고, 한 번의 이동은 해당 단계의 원래 DDIM 이동량의 0.5배로 제한한다. 기본 강도 .2/100 nominal steps이므로 실제 20단계이며, clean_step_ratio .01, 매 단계 보정, backtracking6이다. 수치는 실험 시작값이며 개선이 보장된 값이 아니다.

최종 출력은 VAE로 디코딩한 확산 결과다. 흰색 칠하기, threshold로 잔상 지우기, RGB compositing을 최종 결과에 적용하지 않는다. 마스크·배경 목표는 오직 최적화 지시로만 사용한다. source hash가 바뀌면 지도를 다시 계산하도록 중단한다. 결과와 detector_plan.npz, 저장 모델 해시, 지도 임계값, 모든 단계 trace를 ZIP에 포함한다.

기존 template_structure 지표를 이 모드의 주 손실로 섞지 않는다. legacy source pixel audit은 보조 진단이며 후보 채택에 사용되지 않는다. 일반화/성능 검증 없이 새 방식이 실제 오류를 고친다고 주장하지 않는다.

## 검증

로컬 테스트는 (1) 오류 영역을 밝히는 gradient와 영역 밖 초기 gradient, (2) 빈 지도·지원하지 않는 배경 중단, (3) 학습 체크포인트/동일 추출기 해시 강제, (4) 작은 대체 네트워크와 실제 DDIM에서 고정 지도 가이드가 상태를 바꾸고 paired loss를 줄이는 경로를 검사한다. 실제 사용자 모델/SD1.5 GPU 품질은 Colab 실행 결과로 확인해야 한다.
