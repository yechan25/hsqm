# Generalization experiment: template geometry

This separate experiment retains the known-reference pixel correction notebook as an oracle control. New entry: notebooks/structure_generalization.ipynb, generated by build_structure_generalization.py.

## What changes

- guidance_signal=template_structure invokes the frozen trained stroke extractor on each current predicted glyph, conditioned on a standard character template and its strokes.
- A template descriptor is measured once from the same extractor. The descriptor contains normalized second/third moments (orientation/asymmetry), stroke centers relative to the glyph center/scale, relative stroke size/mass, and dilated pair-contact position/strength. Smooth L1 averages descriptor errors; an RGB range penalty of 0.01 remains. There is no generated RGB versus reference RGB error, erased pixel mask, contour match, or target-coordinate coverage term in this objective.
- Forward masks are actual extractor outputs. Backward ownership is detached and masks carry ink gradients, limiting optimization by relabeling ink. U-Net and extractor weights remain frozen.
- Geometry is translation-invariant in the ideal descriptor, but extractor behavior itself need not be invariant. Contact strength and relative mass remain sensitive to ink/style. Moment descriptors are proxies, not full topology, character recognition, or a guarantee that every spur is detected.

## Initialization and evaluation

Default init_mode=noise uses a seeded Gaussian latent and ALL DDIM timesteps. It never calls VAE encoding on the standard image. The user must enter the correct four-character prompt in the same order as the selected templates. The known template still conditions stroke extraction: this is not reference-free recognition.

init_mode=external accepts a separate RGB sheet (same canvas size, fixed 2x2 character order). This permits a different font without providing its clean target or stroke masks. Arbitrary natural-image text detection/cropping is not implemented. External initialization files are saved for reproducibility. The reference mode remains available as an explicit control.

Each baseline/guided pair shares one initial latent. seed is configurable. Retain all seeds and failures; template-aligned placement, legibility, extra/missing strokes, normal-stroke damage and font-style drift need visual or independent annotation. The optimization descriptor loss must not be the sole success metric. Existing native pixel difference audits are auxiliary only and do not control acceptance in the new mode. The new notebook reports descriptor_scores.csv and downloads a structure debug ZIP; the old pixel-based evaluation notebook is not presented as a generalization score.

The catalog currently supplies TRAIN templates. This tests generation/font/seed transfer under known character conditioning, not unseen-character generalization. To claim held-out character/font generalization, audit extractor training data, split by character/font/source before training, choose thresholds on validation only, and evaluate held-out samples without fitting to test outputs. No new checkpoint has been trained and no actual SD GPU success has been verified locally.

## Local validation

Tests check translation invariance of descriptors, ink-scale invariance of moment components, finite empty-mask values/gradients, and sensitivity/gradient to a wrong-side horizontal extension. A mocked paired pipeline checks noise initialization makes no additional reference VAE encode call, uses the complete schedule, shares initial latents and emits the structure audit. These checks validate implementation paths, not research performance.
